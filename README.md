# MikanPlus

MikanPlus 是一款桌面追番应用，数据来源于[蜜柑计划](https://mikanani.me)。你可以浏览番剧更新、按字幕组订阅，并在应用内管理剧集下载。

## 功能

- 浏览今日更新、每周番剧和剧场版
- 搜索番剧与剧集
- 按字幕组订阅番剧
- 自动获取订阅内容
- 使用磁力链接下载剧集
- 查看下载进度、速度和任务状态
- 下载完成后使用系统播放器打开文件
- 支持深色和浅色主题

## 使用说明

1. 在首页浏览或搜索感兴趣的番剧。
2. 进入番剧详情页，选择字幕组进行订阅或下载。
3. 在订阅页面管理已订阅的番剧。
4. 在设置页面调整主题和下载目录。
