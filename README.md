# MikanPlus

一个桌面追番应用，基于 [gpui](https://gpui.rs) 构建，数据源为[蜜柑计划](https://mikanani.me)。

## 功能

- 今日更新、按星期浏览、剧场版、在线搜索
- 以字幕组为单位订阅。
- 内嵌 BT 下载(磁力链接)。
- 下载完成一键用系统播放器打开
- 深色/浅色主题
