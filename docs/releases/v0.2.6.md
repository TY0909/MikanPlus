## 更新内容

- **同名番剧详情修复**：番剧详情此前按名称缓存，名称相同的两部番剧会互相覆盖——打开第二部时看到的、以及订阅与下载操作作用的都是第一部。现在改为按番剧 ID 缓存，两部各自独立，不会再串页。
- **内部清理**：移除一个无用的空库目标，并更正了若干与当前实现不符的注释与文档说明。不影响功能与既有数据。

## 说明

- 本版本是仓库重建后的第一个版本，作为新的发布起点。此前的历史版本标签与预编译附件已移除，旧的 Release 页面不再可用；各平台预编译安装包自 0.2.6 起重新提供。
- 应用数据、下载目录、订阅记录与封面缓存位置均保持不变，可直接覆盖安装升级。
