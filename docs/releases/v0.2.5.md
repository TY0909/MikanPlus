## 更新内容

- **订阅封面修复**：修复部分订阅（例如从详情页订阅、名称与首页列表不完全一致的番剧）封面不显示的问题；现在会按番剧 ID 自动解析封面。
- **备用域名切换即时生效**：切换「设置 → 备用域名」后，之前加载失败的内容会自动重新请求，加载失败的封面也会立即重试，无需手动刷新。
- **缓存策略调整**：磁盘上只保留封面图缓存；番剧列表、详情、搜索结果改为应用运行期间的内存缓存，避免出现列表陈旧的缓存问题。

## 说明

- 本次包含较大范围的内部重构（按职责拆分模块、状态改由对象持有），不影响功能与既有数据。
- 搜索功能保持不变。
- 应用数据、下载目录、订阅记录与封面缓存位置均保持不变，可直接覆盖安装升级。
