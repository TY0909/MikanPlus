## 更新内容

- **Linux 安装器**：新增基于 AppImage 的 Linux 安装脚本，默认使用用户级安装，也支持系统级安装；可通过 `mikanplus --uninstall` 卸载，并可选择清理应用数据。
- **首页数据更新**：首页按当前日期计算季度，优先加载当季度番剧；当季度没有已发布内容时自动回退到上季度。
- **页面状态保持**：修复首页、详情页和其他顶部页面之间切换时导航状态丢失或返回目标不正确的问题。
- **搜索与详情图片**：修复搜索结果封面加载异常，并改善详情页图片区域的布局，避免因介绍内容较短而被截断。

## 说明

- 应用数据、下载目录、订阅记录与封面缓存位置均保持不变，可直接覆盖安装升级。
- Linux 发布包会同时提供 AppImage、`.deb` 和 tar.gz；AppImage 安装器会校验下载文件的 SHA-256。
